🎓 RBPU HOSHIARPUR - Premium Web Experience
Welcome to the digital home of Rayat Bahra Professional University (Hoshiarpur). This isn't just a university landing page; it’s a high-performance, single-page React application designed to feel as premium and forward-thinking as the institution itself. 🚀

✨ What's Inside?
We’ve built this using a modern tech stack to ensure smooth animations, a clean "editorial" look, and a seamless user experience.

⚡ React-Powered: Built with a state-based navigation system. No clunky page refreshes here.

🎨 Premium Aesthetic: We used a mix of Plus Jakarta Sans for that modern tech feel and Playfair Display for a touch of academic elegance.

📱 Fully Responsive: Whether you’re on a 4K monitor or a budget smartphone, the layout adapts beautifully thanks to Tailwind CSS.

⏳ Sophisticated Loader: A custom-engineered loading screen that sets the tone before the content even hits the screen.

🖼️ Visual Storytelling: High-quality imagery with smooth zoom effects and grayscale-to-color transitions on hover.

🛠️ Technical Stack
Frontend Library: React 18

Styling: Tailwind CSS (CDN)

Typography: Google Fonts (Plus Jakarta Sans & Playfair Display)

Transpiler: Babel Standalone (for that "no-build-step" magic ✨)

Icons/Images: Unsplash & custom assets

📂 Page Structure
The app is broken down into intuitive functional sections:

Home: The "Infinite Potential" hero section + quick stats.

About: A look into the vision and history of the Rayat Bahra Group.

Academics: A grid view of our diverse departments (Engineering, Pharmacy, Law, and more).

Admissions: A simplified 3-step journey with an integrated lead-gen form.

Contact: All the essentials—numbers, emails, and a stylized map view.

🚀 How to Run This
Since this uses CDN links for React and Tailwind, you don't need to deal with npm install or a million node_modules.

Download the index.html file.

Ensure you have your logo named RBPU.png in the same folder.

Open it in any modern browser (Chrome, Safari, Edge).

Enjoy the experience! 🥂

📝 Note on Customization
This is currently a high-fidelity prototype. To take it to production:

Replace the placeholder Unsplash IDs with actual campus photography.

Connect the Admission Form to a backend (like Firebase or a Node.js API).

Switch from the Babel CDN to a proper build tool like Vite for better performance.
