# 🎓 Rayat Bahra Professional University — Hoshiarpur Campus Website

Hey! 👋 This is the source code for the RBPU Hoshiarpur concept website — a clean, modern, and premium-feeling university landing page built entirely in a single HTML file. No backend, no build process, just pure frontend goodness.

---

## 🌟 What Is This?

A fully responsive, multi-page university website concept for **Rayat Bahra Professional University, Hoshiarpur**. It's designed to feel premium and editorial — think less "government college website from 2009," more "top-tier institution that means business." 😄

Built as a concept/portfolio project to showcase what a modern educational institution's digital presence *could* look like.

---

## ✨ Features

- ⏳ **Animated Loader** — A sleek line-progress animation while the page sets up
- 🧭 **Full-screen Navigation Menu** — Slides down from the top with giant typographic menu items
- 🏠 **Multi-page SPA** — Home, About, Academics, Admissions, and Contact — all without any page reloads
- 📜 **Scroll-aware Header** — The navbar goes frosted glass on scroll (because it looks gorgeous)
- 🖼️ **Hover Image Effects** — Grayscale images that pop into full color on hover
- 📊 **Stats Section** — Key numbers displayed with clean typographic hierarchy
- 🗃️ **Academics Grid** — Cards for all departments with image zoom effects
- 📝 **Admissions Form** — A 3-step process layout + a working (UI-only) application form
- 📍 **Contact Page** — Phone, email, address, and a full-width visual map section
- 🦶 **Rich Footer** — Campus list, resources, social links, the works
- 📱 **Fully Responsive** — Looks great on desktop, tablet, and mobile

---

## 🛠️ Tech Stack

| What | How |
|---|---|
| Markup | HTML5 |
| Styling | Tailwind CSS (CDN) |
| UI Framework | React 18 (via CDN, no build step!) |
| JSX Compilation | Babel Standalone |
| Fonts | Plus Jakarta Sans + Playfair Display |

> 💡 **Cool trick used here:** React + JSX is loaded entirely via CDN using Babel Standalone — so you get the full component-based architecture with zero npm setup. It's a neat approach for prototypes and portfolio pieces.

## 🧩 Page Breakdown

### 🏠 Home
The big one. Includes:
- Giant typographic hero with a campus image
- Stats bar (100+ acres, 35k+ students, etc.)
- Chairman's message section with a pull quote card
- Infrastructure features grid (dark theme section)
- Student life photo gallery

### 📖 About
Clean editorial layout telling the university's founding story with a big hero image alongside it.

### 🏫 Academics
A grid of 6 department cards — Engineering, Pharmacy, Management, Medical, Sciences, and Skill Development — each with images that go from grayscale to color on hover.

### 📋 Admissions
A split-layout page: a 3-step process on the left, and a fully styled application form on the right. Clean and approachable.

### 📞 Contact
Phone numbers, emails, address, and a large visual section at the bottom where a real map embed could go.

## 🚀 How to Run

Seriously simple:

```bash
# Clone it
git clone https://github.com/gauravkatnoria12/RBPU-HSP.git

# Open it
open index.html
```

Or just double-click the file. That's it. No terminal needed, no `npm install`, no config. 🙌

Just make sure `RBPU.png` (the logo) is in the same folder as `index.html`.

## 🎨 Design Philosophy

The whole vibe here is **"luxury editorial meets academic authority."** Inspired by the design language of high-end international universities and editorial magazines:

- **Tight tracking** on large headlines for that premium feel
- **Grayscale-to-color** image transitions to keep things focused and then reward interaction
- **Light & dark section alternation** to create visual rhythm as you scroll
- **Oversized typography** used as a design element, not just content
- **Rounded cards** (border-radius `2rem`+) for a modern, approachable softness
